# Dharmanshu Davara - Portfolio

A premium, interactive portfolio website built with React, Framer Motion, and WebGL.

## 🚀 Features

- **Smooth Scroll**: Integrated with Lenis for a buttery-smooth scrolling experience.
- **WebGL Gallery**: A high-performance "Flying Posters" gallery on the Projects page, built with `ogl`.
- **Interactive Parallax**: Dynamic parallax effects and layered image animations.
- **Project Preview**: Click-to-expand lightbox for detailed photography previews.
- **Premium UI**: Modern dark theme with custom gradients and glassmorphism.
- **Responsive Design**: Fully optimized for all screen sizes.

## 🛠️ Tech Stack

- **Frontend**: React.js, Vite
- **Animations**: Framer Motion
- **WebGL**: OGL (Open Graphics Library)
- **Icons**: React Icons
- **Styling**: Vanilla CSS

## 📸 The Gallery

The Projects page features "The Gallery" – a unique WebGL-powered 3D space where photography posters fly and distort as you scroll. Each poster can be clicked to open a high-quality preview modal.

## 📂 Project Structure

- `src/components`: UI components and the WebGL gallery.
- `src/pages`: Home, Projects, and Contact pages.
- `public/`: Assets and photography collection.

## 💻 Local Development

1.  Clone the repository:
    ```bash
    git clone https://github.com/dharmanshudavara-hue/portfollio.git
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```
